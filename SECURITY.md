# Security

Please do not report vulnerabilities or post credentials in public issues or
pull requests. Use the repository's GitHub **Security** tab and **Report a
vulnerability** to send a private report to the maintainers. Include affected
versions, reproduction steps, impact, and any mitigation, while avoiding live
credentials and production data.

The latest release is the version to test and report against. Maintainers will
assess reports and coordinate disclosure and fixes through the private report.
