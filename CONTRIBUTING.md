# Contributing

Bug reports, documentation fixes, and pull requests are welcome. For security
issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

Before filing a bug, search existing issues. Include the Libremapper and
LibreNMS versions, Docker Engine and Compose versions, the affected image tags
or digests, steps to reproduce, expected and actual behavior, and relevant
logs. Remove credentials, tokens, IP addresses, hostnames, and other private
information from shared materials.

For a pull request, describe the problem and the change, link the issue if
there is one, and explain how you verified the change. Contributions are
licensed under GPL-3.0-or-later unless another compatible license is identified;
see [LICENSE](LICENSE) and
[COPYRIGHT.md](COPYRIGHT.md). Submit only material you have the right to
contribute under those terms, and preserve applicable third-party notices.

For setup and checks, see the [contributor guide](dev/README.md).
